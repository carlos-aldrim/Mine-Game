# Jogo da Mímica

## Sobre o Projeto
O **Jogo da Mímica** é um jogo interativo que pode ser jogado individualmente ou em equipe. O objetivo é adivinhar palavras através de gestos, sem falar ou fazer sons. O jogo oferece diversas categorias, diferentes dificuldades e uma experiência imersiva tanto no navegador (Web) quanto em dispositivos móveis (Mobile).

## Funcionalidades
- **Modos de Jogo:**
  - Jogo solo
  - Jogo em equipe (até 6 jogadores)
- **Configuração Personalizada:**
  - Definição do número de jogadores
  - Escolha da quantidade de rodadas
- **Categorias Diversas:**
  - Escolha entre diferentes temas para tornar o jogo mais desafiador
- **Diferentes Níveis de Dificuldade:**
  - Fácil, Médio e Difícil
- **Controle Intuitivo:**
  - **Teclado:** Use as setas "<" e ">" para passar ou acertar uma palavra
  - **Toque na Tela:** Use os botões para interagir
  - **Movimentação do Dispositivo:**
    - Levantar o dispositivo: Marcar como acerto
    - Abaixar o dispositivo: Passar a palavra
- **Sistema de Pontuação:**
  - O jogo analisa a performance dos jogadores e determina o vencedor ao final das rodadas
  - Em caso de empate, o jogo exibe a classificação geral

## Como Jogar
1. Escolha entre o modo **Solo** ou **Equipe**
2. Defina as configurações do jogo (número de jogadores, rodadas e categoria)
3. Escolha a dificuldade desejada
4. Escolha pelo menos 3 categorias
5. Selecione para iniciar e faça as mímicas para que sua equipe adivinhe as palavras
6. Use os controles para registrar acertos ou passar
7. Ao final das rodadas, veja quem foi o vencedor!

## Tecnologias Utilizadas
- **Frontend:** React, JavaScript, CSS Modules.
- **Mobile:** Suporte responsivo para jogabilidade em dispositivos móveis.
- **Interação:** Eventos de teclado, toque na tela e sensores de movimento.

## Instalação e Execução
1. Clone o repositório:
   ```bash
   git clone https://github.com/carlos-aldrim/Mine-Game
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd jogo-mimica
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm start
   ```
5. Acesse no navegador em `http://localhost:3000`
